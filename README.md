# Yunus Tekin | Kişisel web sitesi

Oyun, web, otomasyon ve grafik animasyon portfolyosu. İki dilli (TR/EN), koyu ve açık temalı, derleme adımı olmayan statik site.

- Yayınlanan klasör: `site/`
- İçerik: `site/data/content.js`
- Yerel önizleme: `npm install` ardından `npm start`
- Denetim: `npm test` ve `npm run validate`

[Ember portfolyo şablonu](https://github.com/nazifw/portfolio-site) üzerine kuruldu (MIT, bkz. `LICENSE`). Kaynaklar: `site/kaynak.txt`.
